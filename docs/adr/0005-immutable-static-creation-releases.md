# Serve immutable Creation releases from independent HTTPS hosting

Paseo Relay carries the encrypted WebSocket data path but does not expose daemon-hosted static files, and the daemon normally remains on localhost. Any distributable Phase 2A+ release therefore points to an audited, versioned Creation bundle on an independently trusted HTTPS static origin; self-hosters may publish the same directory on their own trusted HTTPS origin. An immutable path is an operational deployment rule, not cryptographic proof that the origin cannot replace the entry document. CSP, vendored dependencies, recorded audit digests, and origin access controls reduce risk, but resisting a malicious or compromised origin would require platform-supported signed-bundle verification or attestation and remains outside the current boundary. Phase 0/1 private dogfood may use local or temporary spike hosting and is not a release. The daemon owns Relay/WebSocket, Device grants, and product protocol, not production static distribution.
