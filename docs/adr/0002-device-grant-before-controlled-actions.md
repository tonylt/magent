# Controlled actions require an independently revocable Device grant

The current Paseo Relay offer establishes an encrypted connection but makes its holder a trusted daemon operator; it is not device-scoped or independently revocable. Phase 0 and read-only dogfood may import that offer; Phase 0B may also send one non-destructive test Follow-up as an owned-device private transport spike, not as a product capability. Any distributable Follow-up or Stop remains disabled until a trusted full Paseo client approves an R1-specific Device grant with narrow scopes. Each grant is bound to one Host. Its `read` scope covers current and future Workspaces on that Host so Attention cannot silently disappear behind a stale allowlist, but it cannot discover or switch to another Host. Grants contain only capabilities supported by that release: `read` in Phase 2A, `read + follow-up` in the Phase 2B beta, and `stop` only after a separate approval once Phase 2C passes. An upgrade never expands scopes automatically. If secure Creation storage is unavailable, the grant is session-only and must never fall back to long-lived `localStorage`.
